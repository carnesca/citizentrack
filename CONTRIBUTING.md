# Contributing

Thanks for helping improve CitizenTrack.

## Development

1. Fork the repository.
2. Create a feature branch.
3. Install dependencies with `npm install`.
4. Run the app with `npm run dev`.
5. Run `npm run lint` and `npm run build` before opening a pull request.

## Pull Requests

Pull requests are welcome. Keep changes focused, explain the user-facing behavior, and include screenshots for UI updates.

All changes to the default branch should go through pull request review before merge.
